# Foundry VTT systems — releases

Release files of unofficial, non-commercial fan systems for **Foundry VTT v13**. This repository holds only the
install manifests and the release zips; the source code lives elsewhere.

## Install

In Foundry: **Game Systems → Install System**, paste the manifest URL in **Manifest URL**, then **Install**.
Updates then show up in Foundry's own update check.

| System | Manifest URL |
|---|---|
| Only War | `https://raw.githubusercontent.com/dominique-carvalho/foundry-releases/main/only-war/system.json` |
| Dark Heresy 2nd Edition | `https://raw.githubusercontent.com/dominique-carvalho/foundry-releases/main/dark-heresy-2/system.json` |
| Rogue Trader | `https://raw.githubusercontent.com/dominique-carvalho/foundry-releases/main/rogue-trader/system.json` |

Only the person who hosts the game needs the system; players join through the browser.

## Notice

Warhammer 40,000, Only War, Dark Heresy and Rogue Trader belong to Games Workshop and Fantasy Flight Games. These
systems are not affiliated with or endorsed by them, and contain no rulebook text.
